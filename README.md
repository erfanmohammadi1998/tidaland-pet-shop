# 🐾 TidaLand

A responsive pet shop website built with **HTML5** and **CSS3**. The project presents different categories of pet products with a clean, simple, and user-friendly interface.

🌐 **Live Demo:** https://erfan-mohammadi77.github.io/TidaLand/

---

## ✨ Features

* 🐶 Modern Pet Shop Landing Page
* 🦴 Pet Food Section
* 🧸 Pet Toys Section
* ❤️ Pet Care Section
* 📱 Responsive Layout
* 🎨 Clean and Simple UI
* ⚡ Fast Loading

---

## 🛠 Technologies

* HTML5
* CSS3
